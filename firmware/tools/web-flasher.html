Star Tracker — firmware loader

Before you start

  1. Use Google Chrome or Microsoft Edge on a computer (this page uses Web Serial).
  2. Download the latest run of the "Firmware" workflow on GitHub (Actions → Firmware → the run → Artifacts → esp32s3-images-and-flasher) and unzip it.
  3. Connect the head's USB-C port A to the computer with a data cable.

1 · Connect

2 · Load a complete image (first load, or recovery)

Pick st-esp32s3-bringup-full.bin for the bring-up menu (first boards, Stages B–D) or st-esp32s3-system-full.bin for the normal firmware. It is written at address 0 and replaces everything except the PD configuration.


3 · Load the USB-C PD configuration images (once per head)

Pick the two files made with TI's configuration tool (section 9 of the firmware document): port A (TPS25751D) and port B (TPS25752A). They go to the head's pd_cfg area; the bring-up menu item P then writes them into the two configuration EEPROMs.

Normal updates

    
Once the system firmware runs, you do not need this page: open the head's own page (Wi-Fi StarTracker-xxxx, address 192.168.4.1), choose Update and pick star-tracker-update.stfw. The head updates both processors and goes back to the previous firmware by itself if anything fails.
