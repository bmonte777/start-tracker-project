One folder per package. Each holds a `README.md` with what to quote, the quantity breaks (100 / 500 / 1,000), the acceptance criteria and, once they exist, the STEP files, drawings and the quotes received (`quotes/` with the date in each file name). Prices go into the production parts list only from a quote or a cited list price.
